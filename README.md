# Summer-Com1150
My final project is a Drake album tracker. You have the option to add an album, look one up, or view the full list of albums added. To run it you input either 1, 2, 3, or 4 which is quit. If you select 1. it will ask you to input an album name, then it will ask you to enter the date it was released (has to be 4 digits and it will not let you continue unless it is), then it will have you rate the album 1-10. I purposely didnt add a ceiling on ratings because its very normal for me to go outside of the standard 1-10 rating. for example 14/10. This is just me exaggerating that something was just that good.

if you pick 2. which is look up, it will have you input an album name. This isnt case sensitive so it makes look up a bit easier.

if you pick 3. which is list all albums you will first need to enter a password to gain access to the full album list if not youre redirected to the main menu
